# Fuentes

Para mantener la legibilidad orientada a adultos mayores, se recomienda usar una fuente sans-serif limpia (ej. Atkinson Hyperlegible, Lexend, Inter, Readex Pro, VT323 o Pixel Operator para look pixel-art).

El Theme actual usa SystemFont como base para evitar dependencias binarias. Cuando decidas la fuente definitiva, puedes añadir un `.ttf/.otf` aquí y reemplazar `SystemFont` por `FontFile` en `res://core/AccessibleTheme.tres`.

Recomendación inicial: **Atkinson Hyperlegible** (muy buena para legibilidad y accesibilidad).
